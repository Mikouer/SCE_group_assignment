# F2: Graduated meal support

| Field | Description |
| --- | --- |
| ID | F2 |
| Name | Provide graduated meal support |
| Priority | Must. |
| Function | Echo observes response and meal status and, while consumption is unconfirmed, follows the bounded reminder sequence (a sequence of at most three reminders; one postponement, accepted at reminder 1 or 2, pauses it for a delay announced to Cleber (starting value: 30 minutes) and restarts it from the first reminder, so an episode has at most five reminders) without recording uncertain kitchen activity as completed eating. |
