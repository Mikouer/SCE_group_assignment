# UC01-F2-PR2: Bounded and accurate reminder sequence

| Field | Description |
| --- | --- |
| ID | UC01-F2-PR2 |
| Function | [F2](F2.md). |
| Evaluation Method(s) / Measure(s) | [EM-04](../../../1-foundation/human-factors/evaluation-methods/EM-04.md) and [M-04](../../../1-foundation/human-factors/measures/M-04.md) in the formative walkthrough ([ER-01](../../../3-evaluation/reports/ER-01.md), human-facing steps); a staged log-based run with [EM-03](../../../1-foundation/human-factors/evaluation-methods/EM-03.md) is planned for [ER-02](../../../3-evaluation/reports/ER-02.md) (Session 1). |
| Verification Criteria | Before testing F2, kitchen-activity detection must activate the table camera, and the camera must provide consumption and meal-end information. Verify detection through [UC01-F2-PR5](UC01-F2-PR5.md). Then check the bounded reminder sequence (three reminders, at most five in an episode with the restart), one postponement accepted at reminder 1 or 2 with the delay announced, and separation of kitchen activity from eating using [M-04](../../../1-foundation/human-factors/measures/M-04.md). A completion response requires camera evidence of some consumption; finishing the plate is not required. B1 supplies the meal states and cannot verify real detection. |
| Action Sequence step(s) | [UC01](UC01.md), steps 3-5. |
| Assessment | Not assessed against the criteria. The formative walkthrough ([ER-01](../../../3-evaluation/reports/ER-01.md), build B1) covered the human-facing steps; real detection is verified through [UC01-F2-PR5](UC01-F2-PR5.md) and planned for ER-02. |
