# UC01-F2-PR5: Accurate eating confirmation

| Field | Description |
| --- | --- |
| ID | UC01-F2-PR5 |
| Function | [F2](F2.md). |
| Evaluation Method(s) / Measure(s) | [EM-05](../../../1-foundation/human-factors/evaluation-methods/EM-05.md) and [M-06](../../../1-foundation/human-factors/measures/M-06.md). Not covered by the walkthrough ([EM-04](../../../1-foundation/human-factors/evaluation-methods/EM-04.md)) or by [M-04](../../../1-foundation/human-factors/measures/M-04.md), which use facilitator-selected meal-state events. |
| Verification Criteria | Against an independent meal observation record ([M-06](../../../1-foundation/human-factors/measures/M-06.md)), check that kitchen activity activates the table camera and that camera-confirmed consumption matches actual eating. The episode ends when consumption has been observed and either the camera detects meal end or Cleber says he is done. Some consumption is sufficient for his completion response; finishing the plate is not required. Kitchen activity, plate movement and speech alone do not confirm eating. Report correct, false and missed confirmations and unknown outcomes separately. |
| Action Sequence step(s) | [UC01](UC01.md), steps 3-5 and 8. |
| Assessment | Not assessed. Added after the formative cycle ([ER-01](../../../3-evaluation/reports/ER-01.md)) was planned, so it is untested and not covered by that report. |
