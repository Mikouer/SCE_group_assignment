# UC01-F2-PR5: Accurate eating confirmation and presence detection

| Field | Description |
| --- | --- |
| ID | UC01-F2-PR5 |
| Function | [F2](F2.md). |
| Evaluation Method(s) / Measure(s) | [EM-05](../../../1-foundation/human-factors/evaluation-methods/EM-05.md) and [M-06](../../../1-foundation/human-factors/measures/M-06.md). Not covered by the walkthrough ([EM-04](../../../1-foundation/human-factors/evaluation-methods/EM-04.md)) or by [M-04](../../../1-foundation/human-factors/measures/M-04.md), which use facilitator-selected meal-state events. |
| Verification Criteria | Against an independent observation record of each intended meal ([M-06](../../../1-foundation/human-factors/measures/M-06.md)), "eating confirmed" and Cleber's presence in the kitchen match what actually happened. Report the counts of correct confirmations, false confirmations (a meal logged as eaten that was not), missed confirmations and unknown outcomes separately, with the meal totals. The detection conditions below define when "eating confirmed" may be recorded: (1) kitchen activity is detected, then the table-only camera is activated; (2) the camera records the meal event at the table; (3) [define: what the camera must observe, and how long, before a meal counts as eaten]. Kitchen activity alone, the plate leaving the table, or Cleber saying he is done never confirm eating on their own: they are logged as uncertain or as supporting information. [Acceptable false-confirmation level: to be agreed by the team.] |
| Action Sequence step(s) | [UC01](UC01.md), steps 3-5 and 8. |
| Assessment | Not assessed. Added after the formative cycle ([ER-01](../../../3-evaluation/reports/ER-01.md)) was planned, so it is untested and not covered by that report. |
