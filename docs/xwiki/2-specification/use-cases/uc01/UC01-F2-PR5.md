# UC01-F2-PR5: Accurate eating confirmation and presence detection

| Field | Description |
| --- | --- |
| ID | UC01-F2-PR5 |
| Function | [F2](F2.md). |
| Evaluation Method(s) / Measure(s) | [EM-05](../../../1-foundation/human-factors/evaluation-methods/EM-05.md) and [M-06](../../../1-foundation/human-factors/measures/M-06.md). Not covered by the walkthrough ([EM-04](../../../1-foundation/human-factors/evaluation-methods/EM-04.md)) or by [M-04](../../../1-foundation/human-factors/measures/M-04.md), which use facilitator-selected meal-state events. |
| Verification Criteria | Against an independent observation record of each intended meal ([M-06](../../../1-foundation/human-factors/measures/M-06.md)),"eating confirmed" and Cleber's presence in the kitchen match what actually happened. Log and report the counts of correct confirmations, false confirmations such as a meal logged as eaten but actually was not, missed confirmations and unknown outcomes separately, with the meal totals. The following detection conditions define when "eating confirmed" will be recorded: (1) kitchen activity is detected, then the table-only camera is activated; (2) the camera records the meal event at the kitchen table; (3) the camera will observe the consumption of the plate considering what was on the plate and how much of it was eaten, in how many minutes, before a meal counts as eaten. Kitchen activity alone, the plate leaving the table, or Cleber saying he is done never confirms eating on their own, but they are all complimentary to each other: they are logged as uncertain or as supporting information when performed alone. |
| Action Sequence step(s) | [UC01](UC01.md), steps 3-5 and 8. |
| Assessment | Not assessed. Added after the formative cycle ([ER-01](../../../3-evaluation/reports/ER-01.md)) was planned, so it is untested and not covered by that report. |
