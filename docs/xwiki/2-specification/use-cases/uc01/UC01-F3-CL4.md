# UC01-F3-CL4: Unresolved meal escalation

| Field | Description |
| --- | --- |
| ID | UC01-F3-CL4 |
| Function | [F3](F3.md). |
| Serves Objective | [OBJ-01](../OBJ-01.md). |
| Expected Effect | The unresolved-meal alert reaches Sarah in a form she understands and can act on, so a failed reminder sequence does not remain unnoticed until her next visit. |
| Grounding | [SA-01](../../../1-foundation/operational-demands/activities/SA-01.md), [PS-01](../../../1-foundation/operational-demands/problem-scenarios/PS-01.md), [HV-01](../../../1-foundation/human-factors/human-values/HV-01.md), [HFC-01](../../../1-foundation/human-factors/concepts/HFC-01.md) (understandable information), [HP-01](../../personas/human/HP-01.md) and [TDP-01](../../team-design-patterns/TDP-01.md). |
| Evaluation Method(s) / Measure(s) | [EM-02](../../../1-foundation/human-factors/evaluation-methods/EM-02.md) and [M-05](../../../1-foundation/human-factors/measures/M-05.md) (Part A). |
| Validation Criteria | The person playing Sarah scores the alert at a Part A mean of at least 4 out of 5 (proposed target, to be confirmed before the session), names the correct meal and the correct reason (refusal or no response) for every scripted alert, and states a follow-up action. This shows the alert is understandable; it does not show that a real Sarah is always available or that nutrition improves. |
| Action Sequence step(s) | [UC01](UC01.md), steps 6-7. |
| Assessment | Not assessed; validation is planned in a later session. |
