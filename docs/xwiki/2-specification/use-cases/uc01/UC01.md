## Action sequence

1. Echo detects the predefined condition for a meal reminder (planned mealtime reached and the prepared meal appears untouched).
2. Echo gives a gentle prompt on the speakers using [IDP-01](../../interaction-design-patterns/IDP-01.md) ([F1](F1.md)). This is a deliberate addition
   to Cleber's existing activity in [SA-01](../../../1-foundation/operational-demands/activities/SA-01.md).
3. Echo observes the response and available meal information ([F2](F2.md)). The table camera stays off until kitchen activity occurs; it then
   records the meal event. If Cleber does not come to the kitchen, the camera stays off, eating stays unconfirmed and the sequence
   continues. Activity alone is not treated as eating. This is a deliberate design addition from [TDP-01](../../team-design-patterns/TDP-01.md).
4. If eating is confirmed, Echo ends the interaction. If Cleber does not respond, or eating remains uncertain, Echo waits the
   predefined interval and provides another gentle reminder ([F2](F2.md)). If Cleber says he does not want to eat, the sequence
   pauses and restarts from the first reminder; this can happen once, and a second postponement does not reset it.
5. Echo follows the bounded sequence of at most three reminders without increasing pressure or volume.
6. If eating remains unconfirmed after the final reminder, Echo informs Sarah, distinguishing refusal, non-response and uncertain
   consumption. If Sarah does not respond, the message is repeated once and Gilbert is then notified ([F3](F3.md)).
7. After confirmation or escalation, Echo stops reminders, the camera becomes inactive, and Echo returns to rest. If Cleber eats after
   Sarah calls, Sarah gets a short "resolved" update ([F3](F3.md)).
8. If the table camera sees the plate leave the table, Echo logs the time until the plate returns ([F4](F4.md)). It sends no
   reminders while the plate is away, and a plate that does not return is logged as not returned. This has no counterpart
   in Cleber's existing activity and is a deliberate design addition.
9. Echo records the episode and includes it in Sarah's visit summary, listing items needing attention first and showing any data gap
   ([F4](F4.md)). This is a deliberate design addition.
