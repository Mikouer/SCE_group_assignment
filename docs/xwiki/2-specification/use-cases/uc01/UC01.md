## Action sequence

1. Echo detects the predefined condition for a meal reminder.
2. Echo gives a gentle prompt using [IDP-01](../../interaction-design-patterns/IDP-01.md) ([F1](F1.md)). This is a deliberate addition
   to Cleber's existing activity in [SA-01](../../../1-foundation/operational-demands/activities/SA-01.md).
3. Echo observes the response and available meal information ([F2](F2.md)). This is
   a deliberate design addition from [TDP-01](../../team-design-patterns/TDP-01.md).
4. If eating is confirmed, Echo ends the interaction. If Cleber refuses,
   does not respond, or eating remains uncertain, Echo waits the predefined
   interval and provides another gentle reminder ([F2](F2.md)).
5. Echo follows the bounded sequence of at most three reminders without
   increasing pressure or volume.
6. If eating remains unconfirmed after the final reminder, Echo informs Sarah,
   distinguishing refusal, non-response and uncertain consumption ([F3](F3.md)).
7. After confirmation or escalation, Echo stops reminders and returns to rest
   ([F3](F3.md)).
