# UC01-F1-CL1: Initial reminder effectiveness

| Field | Description |
| --- | --- |
| ID | UC01-F1-CL1 |
| Function | [F1](F1.md). |
| Serves Objective | [OBJ-01](../OBJ-01.md). |
| Expected Effect | Echo's prompt, heard on the speakers in whichever room Cleber is in, increases the likelihood that he notices the reminder and starts eating within the response window. |
| Grounding | [SA-01](../../../1-foundation/operational-demands/activities/SA-01.md) (existing workarounds fail when Cleber is in another room or asleep), [PS-01](../../../1-foundation/operational-demands/problem-scenarios/PS-01.md), [HFC-01](../../../1-foundation/human-factors/concepts/HFC-01.md), [TDP-01](../../team-design-patterns/TDP-01.md) and [IDP-01](../../interaction-design-patterns/IDP-01.md). |
| Evaluation Method(s) / Measure(s) | [EM-01](../../../1-foundation/human-factors/evaluation-methods/EM-01.md) and [M-02](../../../1-foundation/human-factors/measures/M-02.md). |
| Validation Criteria | The initial-reminder success rate ([M-02](../../../1-foundation/human-factors/measures/M-02.md)) is at least half of the eligible first reminders, within the response window. This starting target is proposed and to be confirmed before the session. With a stand-in participant it indicates that the interaction can work, not that it works for people with dementia. |
| Action Sequence step(s) | [UC01](UC01.md), steps 1-3. |
| Assessment | Not assessed; no evaluation of this Claim is planned yet. The role-play and questionnaire methods named above are candidates for a later session. |
