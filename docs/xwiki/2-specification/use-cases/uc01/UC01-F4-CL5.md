# UC01-F4-CL5: Informed caregiver follow-up

| Field | Description |
| --- | --- |
| ID | UC01-F4-CL5 |
| Function | [F4](F4.md). |
| Serves Objective | [OBJ-01](../OBJ-01.md). |
| Expected Effect | Sarah's visit summary lets her understand what happened between visits (unresolved meals, reminder timing, plate-away times, data gaps) and decide whether a call or visit is needed, without reading missing data as a good day. |
| Grounding | [PS-01](../../../1-foundation/operational-demands/problem-scenarios/PS-01.md) (Sarah does not notice a skipped meal until her next visit), [HV-03](../../../1-foundation/human-factors/human-values/HV-03.md), [HFC-01](../../../1-foundation/human-factors/concepts/HFC-01.md) (understandable information), [HP-01](../../personas/human/HP-01.md) and [TDP-01](../../team-design-patterns/TDP-01.md). |
| Evaluation Method(s) / Measure(s) | Planned for the summative test ([ER-02](../../../3-evaluation/reports/ER-02.md), Session 2): [EM-02](../../../1-foundation/human-factors/evaluation-methods/EM-02.md) and [M-05](../../../1-foundation/human-factors/measures/M-05.md) (Part B). |
| Validation Criteria | The family caregiver in the Sarah role scores the summary at a Part B mean of at least 4 out of 5 (starting target, confirmed before the session) and correctly identifies the unresolved meal and the data gap in the summary. This tests readability, not a caregiver's workload. |
| Action Sequence step(s) | [UC01](UC01.md), steps 8-9. |
| Assessment | Not assessed. The formative walkthrough ([ER-01](../../../3-evaluation/reports/ER-01.md)) did not address this Claim because nobody played Sarah and the summary was not walked; it is planned for [ER-02](../../../3-evaluation/reports/ER-02.md) (Session 2). |
