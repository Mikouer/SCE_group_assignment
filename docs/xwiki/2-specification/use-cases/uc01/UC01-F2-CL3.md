# UC01-F2-CL3: Retained perceived autonomy

| Field | Description |
| --- | --- |
| ID | UC01-F2-CL3 |
| Function | [F2](F2.md). |
| Serves Objective | [OBJ-02](../OBJ-02.md). |
| Expected Effect | Limiting reminders, keeping them gentle and allowing one postponement reduces the risk of support being experienced as controlling or too persistent. |
| Grounding | [HV-02](../../../1-foundation/human-factors/human-values/HV-02.md), [HFC-01](../../../1-foundation/human-factors/concepts/HFC-01.md), [HFC-02](../../../1-foundation/human-factors/concepts/HFC-02.md) and [IDP-01](../../interaction-design-patterns/IDP-01.md). |
| Evaluation Method(s) / Measure(s) | In the current cycle, the open-ended follow-up questions of the cognitive walkthrough ([EM-04](../../../1-foundation/human-factors/evaluation-methods/EM-04.md)) with the open question of [M-03](../../../1-foundation/human-factors/measures/M-03.md). Planned for a later session: [EM-02](../../../1-foundation/human-factors/evaluation-methods/EM-02.md) with the [M-03](../../../1-foundation/human-factors/measures/M-03.md) Likert questionnaire. |
| Validation Criteria | After the repeated reminder episodes, the [M-03](../../../1-foundation/human-factors/measures/M-03.md) mean is at least 4 out of 5 (proposed target, to be confirmed before the session), and the observer notes no avoidance of Echo. The questionnaire is an unvalidated adaptation answered by a stand-in participant, so the result speaks to how the interaction felt to that person. In the walkthrough follow-up no numeric criterion is applied: the evaluators' answers are coded (pressure, confusion, none, other) and read as a first, formative look. |
| Action Sequence step(s) | [UC01](UC01.md), steps 3-5. |
| Assessment | Not assessed against the criteria; the follow-up questions in [ER-01](../../../3-evaluation/reports/ER-01.md) give a formative first look. |
