# UC01-F2-CL2: Follow-up reminder effectiveness

| Field | Description |
| --- | --- |
| ID | UC01-F2-CL2 |
| Function | [F2](F2.md). |
| Serves Objective | [OBJ-01](../OBJ-01.md). |
| Expected Effect | Graduated follow-ups increase the chance of eating after an initially missed or ignored reminder. |
| Grounding | [SA-01](../../../1-foundation/operational-demands/activities/SA-01.md), [HFC-01](../../../1-foundation/human-factors/concepts/HFC-01.md), [TDP-01](../../team-design-patterns/TDP-01.md) and [IDP-01](../../interaction-design-patterns/IDP-01.md). |
| Evaluation Method(s) / Measure(s) | [EM-01](../../../1-foundation/human-factors/evaluation-methods/EM-01.md) and [M-02](../../../1-foundation/human-factors/measures/M-02.md). |
| Validation Criteria | The follow-up rescue rate ([M-02](../../../1-foundation/human-factors/measures/M-02.md)) is at least half of the episodes in which the first reminder was unsuccessful and a follow-up was given. This starting target is proposed and to be confirmed before the session; the response window is the one defined in [M-02](../../../1-foundation/human-factors/measures/M-02.md). |
| Action Sequence step(s) | [UC01](UC01.md), steps 3-5. |
| Assessment | Not assessed; no evaluation of this Claim is planned yet. The role-play and questionnaire methods named above are candidates for a later session. |
