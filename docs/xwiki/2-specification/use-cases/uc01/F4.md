# F4: Log meal events and report to Sarah

| Field | Description |
| --- | --- |
| ID | F4 |
| Name | Log meal events and report to Sarah |
| Priority | Should. |
| Function | Echo records timestamped events for each meal episode (trigger, reminders, responses and postponement, kitchen entry, the plate leaving and returning, eating outcome, escalation) and gives Sarah a summary for her visits. The summary lists items needing attention first and states when data is missing rather than showing a clean day. Plate-away time is only logged: the table camera sees the plate leave and return, no reminder or alert is sent, a plate that does not return is logged as not returned, and away times over one hour are highlighted for Sarah. |
