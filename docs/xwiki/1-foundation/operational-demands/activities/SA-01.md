# SA-01: Forgetting to eat

| Field | Description |
| --- | --- |
| ID | SA-01 |
| Name | Forgetting to eat |
| Status | In Progress |
| Evidence basis | Gilbert's observations during visits to Cleber's home, as reported in the project document. The observation records were not supplied with the document. |
| Goal | Eat regularly and in healthy amounts. |
| Performing Actor(s) | Cleber ([ST-01](../stakeholders/ST-01.md)). |
| Trigger | The need to eat properly and regularly throughout the day. |
| Constituent Tasks | Get up, walk to the kitchen, heat a prepared meal, and eat. |
| Context | Cleber lives alone in an apartment. |
| Frequency and duration | Three meals a day, approximately 30 minutes to one hour per meal; this estimate is reported in the source document. |
| Tools and artifacts | Cutlery, a plate, a meal from the fridge, and a microwave. |
| Existing workarounds | Alarms and written notes. |
| Observed breakdowns | Cleber is in a different room from an alarm or note approximately two to three times a week. He also falls asleep and misses an alarm approximately two to three times a week. These frequencies are source estimates, not independently verified measurements. |

The resulting meal-related breakdown is described in [PS-01](../problem-scenarios/PS-01.md). The proposed
system interaction is specified in [UC01](../../../2-specification/use-cases/uc01/UC01.md); it is not part of the current activity.
