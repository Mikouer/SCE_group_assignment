# HV-02: Achievement

| Field | Description |
| --- | --- |
| ID | HV-02 |
| Name | Achievement |
| Status | In Progress |
| Evidence basis | Schwartz's theory of basic values, with independence used as the project's situated interpretation of achievement. |
| Situated meaning | Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)) wants to manage his daily needs without relying unnecessarily on Sarah ([ST-03](../../operational-demands/stakeholders/ST-03.md)). Sarah wants him to become more autonomous and need less assistance. |
| Held by | Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)), with very high priority, Gilbert ([ST-02](../../operational-demands/stakeholders/ST-02.md)), and Sarah ([ST-03](../../operational-demands/stakeholders/ST-03.md)). |
| Intrinsic or instrumental | Intrinsic, as recorded in the source. |
| Recognition criteria | Served when Cleber manages meals and familiar activities independently when able. Violated when support unnecessarily removes his opportunity to decide or act for himself. |
| Source | Schwartz, S. H. (2012), [An Overview of the Schwartz Theory of Basic Values](https://doi.org/10.9707/2307-0919.1116). |

The interpretation here is project-specific: independence is not claimed to be
the complete theoretical definition of achievement. [HFC-02](../concepts/HFC-02.md) provides more direct
research grounding for agency in dementia self-management. [M-03](../measures/M-03.md) addresses
perceived choice and control.
