**# HV-02: Achievement**

| Field | Description |
| --- | --- |
| ID | HV-02 |
| Name | Achievement |
| Status | In Progress |
| Evidence basis | Proxy interviews with ST-01, observations by ST-02 |
| Situated meaning | Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)) wants to manage his daily needs without relying unnecessarily on Sarah ([ST-03](../../operational-demands/stakeholders/ST-03.md)). |
| Held by | Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)), with very high priority. |
| Intrinsic or instrumental | Intrinsic, as recorded in the source. |
| Recognition criteria | Served: ST-01 is able to manage his daily meal-related needs with the level of assistance he considers acceptable.<br><br>Violated: ST-01 repeatedly depends on others for meal-related decisions or actions that he would prefer to manage himself. |
| Source | Schwartz, S. H. (2012), [An Overview of the Schwartz Theory of Basic Values](https://doi.org/10.9707/2307-0919.1116). |

The interpretation here is project-specific: independence is not claimed to be the complete theoretical definition of achievement. [HFC-02](../concepts/HFC-02.md) provides more direct research grounding for agency in dementia self-management. [M-03](../measures/M-03.md) addresses perceived choice and control.
