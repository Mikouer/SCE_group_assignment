**# HV-02: Achievement**

| Field | Description |
| --- | --- |
| ID | HV-02 |
| Name | Achievement |
| Status | Finalized |
| Evidence basis | Case description, interpreted with Schwartz [1]. Provisional: no direct contact with the stakeholder group. |
| Situated meaning | Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)) wants to manage his daily needs without relying unnecessarily on Sarah ([ST-03](../../operational-demands/stakeholders/ST-03.md)). |
| Held by | Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)), with very high priority. |
| Intrinsic or instrumental | Intrinsic. |
| Recognition criteria | Served: ST-01 is able to manage his daily meal-related needs with the level of assistance he considers acceptable.<br><br>Violated: ST-01 repeatedly depends on others for meal-related decisions or actions that he would prefer to manage himself. |
| Source | Schwartz [1]. |

The interpretation here is project-specific: independence is one situated reading of achievement. [HFC-02](../concepts/HFC-02.md) provides more direct research grounding for agency in dementia self-management. [M-03](../measures/M-03.md) addresses perceived choice and control.

## References
