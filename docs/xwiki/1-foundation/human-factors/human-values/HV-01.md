**# HV-01: Security**

| Field | Description |
| --- | --- |
| ID | HV-01 |
| Name | Security |
| Status | In Progress |
| Evidence basis | Interviews with ST-01 and ST-03, health check-up results. Provisional. |
| Situated meaning | For ST-01: Avoiding health risks from repeatedly missing meals. For ST-02: Knowing that ST-01 eats properly and meal-related risks are noticed. For ST-03, ST-04: Knowing that ST-01 is protected from meal-related risks. |
| Held by | Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)) and Gilbert ([ST-02](../../operational-demands/stakeholders/ST-02.md)), with high priority; also high priority for Sarah ([ST-03](../../operational-demands/stakeholders/ST-03.md)) and for Hanz ([ST-04](../../operational-demands/stakeholders/ST-04.md)). |
| Intrinsic or instrumental | Instrumental because it leads to Health. |
| Recognition criteria | Served: Meal-related risks are noticed and addressed when necessary.<br><br>Violated: Repeated missed meals or related risks remain unnoticed or unaddressed. |
| Source | Schwartz, S. H. (2012), [An Overview of the Schwartz Theory of Basic Values](https://doi.org/10.9707/2307-0919.1116). |

[M-01](../measures/M-01.md) addresses the meal-related aspect. The trade-off with achievement is documented in [VT-01](../value-tensions/VT-01.md) and the design rationale in [OS-01](../../../2-specification/objective-stories/OS-01.md).
