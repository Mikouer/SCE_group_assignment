# HV-01: Security

| Field | Description |
| --- | --- |
| ID | HV-01 |
| Name | Security |
| Status | In Progress |
| Evidence basis | Schwartz's theory of basic values, interpreted for the project's stakeholder descriptions. |
| Situated meaning | For Cleber, being safe when eating and remembering to eat by himself. |
| Held by | Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)) and Gilbert ([ST-02](../../operational-demands/stakeholders/ST-02.md)), with high priority; also a concern for Sarah ([ST-03](../../operational-demands/stakeholders/ST-03.md)) and a high priority for Hanz ([ST-04](../../operational-demands/stakeholders/ST-04.md)). |
| Intrinsic or instrumental | Intrinsic, as recorded in the source. |
| Recognition criteria | Served when Cleber can consume meals safely and navigate familiar surroundings. Unmet needs are indicated by meal-related problems or recurrent difficulty with directions; receiving appropriate assistance is not itself evidence that security has been violated. |
| Source | Schwartz, S. H. (2012), [An Overview of the Schwartz Theory of Basic Values](https://doi.org/10.9707/2307-0919.1116). |

[M-01](../measures/M-01.md) addresses the meal-related aspect. The trade-off with achievement is
documented in [VT-01](../value-tensions/VT-01.md) and the design rationale in [OS-01](../../../2-specification/objective-stories/OS-01.md).
