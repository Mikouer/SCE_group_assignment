# VT-01: Security vs independent meal support

| Field | Description |
| --- | --- |
| ID | VT-01 |
| Name | Security vs independent meal support |
| Status | In Progress. |
| Evidence basis | The trade-off described in [OS-01](../../../2-specification/objective-stories/OS-01.md), [HP-01](../../../2-specification/personas/human/HP-01.md), [TECH-01](../../technology/TECH-01.md) and [TECH-02](../../technology/TECH-02.md). |
| Values in tension | Security ([HV-01](../human-values/HV-01.md)) motivates timely support; achievement/independence ([HV-02](../human-values/HV-02.md)) motivates giving Cleber control before Sarah is involved. |
| Domain area | Safety, autonomy and caregiver availability. |
| Nature of the conflict | Immediate escalation can undermine Cleber's opportunity to act independently and interrupt Sarah. Waiting too long can leave an unresolved meal unnoticed. Monitoring that confirms eating, such as the table camera, adds to security but can make Cleber feel watched rather than supported, which also works against his independence (see [TECH-02](../../technology/TECH-02.md) and [TECH-03](../../technology/TECH-03.md)). |
| Non-negotiable floor | No hard safety threshold is cited, and a safe escalation interval is not yet established. For the camera, a regulatory floor applies: camera use is subject to data-protection law and informed consent, which bounds how the camera may be used, not the reminder timing. |
| Current resolution | Provisional: Cleber is given the first opportunity to manage the situation himself through a bounded reminder sequence. He may postpone the interaction once, after which the sequence restarts from the first reminder; a second postponement is not permitted. If the meal remains unresolved after the bounded sequence, the system escalates to Sarah, as specified in [F2](../../../2-specification/use-cases/uc01/F2.md), [F3](../../../2-specification/use-cases/uc01/F3.md), [TDP-01](../../../2-specification/team-design-patterns/TDP-01.md) and [IDP-01](../../../2-specification/interaction-design-patterns/IDP-01.md). |
| Alternatives considered | Immediate caregiver involvement versus relying only on Cleber; immediate involvement risks undermining independence and interrupting Sarah, while relying only on Cleber risks an unnoticed missed meal. |
| Status of the tension | Open: timing, acceptance and the effect on independence have not been validated. |
