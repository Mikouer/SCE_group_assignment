# VT-01: Security vs independent meal support

| Field | Description |
| --- | --- |
| ID | VT-01 |
| Name | Security vs independent meal support |
| Status | In Progress; provisionally documented from the source's existing rationale. |
| Evidence basis | The trade-off described in [OS-01](../../../2-specification/objective-stories/OS-01.md), [HP-01](../../../2-specification/personas/human/HP-01.md), [TECH-01](../../technology/TECH-01.md) and [TECH-02](../../technology/TECH-02.md). This record organises that rationale; it is not an evaluated result. |
| Values in tension | Security ([HV-01](../human-values/HV-01.md)) motivates timely support; achievement/independence ([HV-02](../human-values/HV-02.md)) motivates giving Cleber control before Sarah is involved. |
| Domain area | Safety, autonomy and caregiver availability. |
| Nature of the conflict | Immediate escalation can undermine Cleber's opportunity to act independently and interrupt Sarah. Waiting too long can leave an unresolved meal unnoticed. |
| Non-negotiable floor | No cited hard safety threshold or regulatory floor is supplied. A safe escalation interval remains to be established; absence of a supplied citation is not evidence that no applicable requirement exists. |
| Current resolution | Provisional: Cleber is given the first opportunity to manage the situation himself through a bounded reminder sequence. He may postpone the interaction once, after which the sequence restarts from the first reminder; a second postponement is not permitted. If the meal remains unresolved after the bounded sequence, the system escalates to Sarah, as specified in [F2](../../../2-specification/use-cases/uc01/F2.md), [F3](../../../2-specification/use-cases/uc01/F3.md), [TDP-01](../../../2-specification/team-design-patterns/TDP-01.md) and [IDP-01](../../../2-specification/interaction-design-patterns/IDP-01.md). |
| Alternatives considered | Immediate caregiver involvement versus relying only on Cleber; the source explains risks of both. |
| Status of the tension | Open: timing, acceptance and the effect on independence have not been validated. |
