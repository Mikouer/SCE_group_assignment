# EM-01: Structured meal observation

| Field | Description |
| --- | --- |
| ID | EM-01 |
| Name | Structured meal observation |
| Status | In Progress |
| Evidence basis | Candidate formative evaluation method based on [SA-01](../../operational-demands/activities/SA-01.md); no completed protocol or validation study is supplied. |
| Procedure summary | Observe a representative meal situation. Record whether Cleber notices a prompt, starts the eating activity and completes the meal. For a prototype role-play, record the interaction flow separately from claims about the intended user population. |
| Purpose | Validation in the intended setting; a role-play can also inspect specified interaction behaviour without establishing behavioural effectiveness. |
| Human subjects required | Yes for the proposed observation with Cleber. |
| Measures used | [M-01](../measures/M-01.md) and [M-02](../measures/M-02.md). |
| Cost and feasibility | Moderate: participant time and structured observation are required, with little specialist equipment beyond the proposed observation setup. |
| Known limitations | Short-term observation may not reflect long-term home behaviour. Observers can influence behaviour, and a tester acting as Cleber is not a representative participant with dementia. |

[ER-01](../../../3-evaluation/reports/ER-01.md) records the proposed prototype evaluation plan, not a completed study.
