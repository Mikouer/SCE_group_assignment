# M-03: Autonomy retention

| Field | Description |
| --- | --- |
| ID | M-03 |
| Name | Autonomy retention |
| Status | In Progress |
| Evidence basis | Proposed assessment of self-perception and perceived choice. No named instrument or validation-study citation was supplied. |
| Construct measured | Cleber's perceived choice and control while receiving eating-related support. |
| Type | Qualitative in the current proposal. |
| Instrument or procedure | Brief questions about accepting, rejecting or avoiding reminders, complemented by interviews and behavioural observation where appropriate. |
| Scoring or coding scheme | Not yet specified. Record responses and avoidance observations; do not calculate an unsupported scale score. |
| Validity and reliability | Any adapted instrument for people with dementia is provisional. [HFC-02](../concepts/HFC-02.md) supports the relevance of agency but does not validate this measure. |
| Serves | Validation. |
| Burden | Moderate; consent, accessible communication and cognitive load require attention. |

Used by [EM-02](../evaluation-methods/EM-02.md) to examine [OBJ-02](../../../2-specification/use-cases/OBJ-02.md) and [UC01-F2-CL3](../../../2-specification/use-cases/uc01/UC01-F2-CL3.md). Selecting an instrument,
its source, scoring rules and acceptable change criterion remains outstanding.
