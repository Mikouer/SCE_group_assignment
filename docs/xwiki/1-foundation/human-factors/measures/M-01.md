# M-01: Meal completion rate

| Field | Description |
| --- | --- |
| ID | M-01 |
| Name | Meal completion rate |
| Status | In Progress |
| Evidence basis | Bespoke measure derived from the breakdowns in [SA-01](../../operational-demands/activities/SA-01.md) and [PS-01](../../operational-demands/problem-scenarios/PS-01.md). |
| Construct measured | The extent to which Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)) consumes intended meals instead of forgetting, skipping or leaving them unfinished. |
| Type | Quantitative. |
| Instrument or procedure | In the planned summative test (ER-02, Session 2), with real meals, compare the plate-based intake estimate with an independent observer's record of what Cleber actually consumes. Record the portion before the meal, the amount remaining afterwards, and food discarded, transferred or shared. If consumption cannot be established, mark the observation as unknown. The procedure is described in [EM-05](../evaluation-methods/EM-05.md). |
| Scoring or coding scheme | Score a fully consumed intended meal as 1 and a partly consumed meal as the consumed proportion between 0 and 1. For a three-meal day, average the three proportions. The case description gives a 30-day average for a month; missing-observation rules and other reporting periods still need to be specified. |
| Validity and reliability | Bespoke, not independently validated. Sensor accuracy, portion estimation and inter-observer agreement remain to be established. |
| Serves | Validation. |
| Burden | Low if suitable logging is automated; structured observation may require additional personnel. |

**Not used in the formative cycle.** This measure needs an observed real meal, which the [AT-01](../../../3-evaluation/artifacts/AT-01.md) walkthrough did not have. It is planned for the summative test (ER-02, Session 2), where real meals are observed for about a week per resident ([EM-01](../evaluation-methods/EM-01.md), [EM-05](../evaluation-methods/EM-05.md)).
