# M-07: Caregiver alert delivery time

| Field | Description |
| --- | --- |
| ID | M-07 |
| Name | Caregiver alert delivery time |
| Status | In Progress |
| Evidence basis | Bespoke candidate timing measure derived from the delayed awareness described in [PS-01](../../operational-demands/problem-scenarios/PS-01.md) and the alert delivery expected in [UC01-F3-CL4](../../../2-specification/use-cases/uc01/UC01-F3-CL4.md). No validation evidence is available. |
| Construct measured | Time from the escalation condition being met to the alert appearing on the intended recipient's interface. |
| Type | Quantitative. |
| Instrument or procedure | In [EM-05](../evaluation-methods/EM-05.md), record both timestamps using a common clock or synchronised clocks, and identify the intended recipient for each alert. |
| Scoring or coding scheme | Calculate the elapsed time in seconds for each delivered alert. Report individual times, the number of required alerts and the number undelivered by the end of the observation window. Set the observation window before testing. Compare times with an agreed delivery requirement when one has been specified. |
| Validity and reliability | Bespoke and unvalidated. Results depend on the notification channel and network conditions. A prototype showing only alert generation supports generation-time checks; delivery measurement requires a receiving interface. A delivery-time acceptance limit remains to be specified. |
| Serves | Verification. |
| Burden | An evaluator, timestamp records and sender and recipient interfaces. Staged alerts can be tested without a caregiver participant. |

Planned for the summative test (ER-02, Session 1), not assessed in the formative walkthrough. Used by [EM-05](../evaluation-methods/EM-05.md) for [F3](../../../2-specification/use-cases/uc01/F3.md), providing supporting evidence for [UC01-F3-CL4](../../../2-specification/use-cases/uc01/UC01-F3-CL4.md). Alert understanding is assessed through [M-05](M-05.md).
