# M-06: Meal-status detection performance

| Field | Description |
| --- | --- |
| ID | M-06 |
| Name | Meal-status detection performance |
| Status | Not Started |
| Evidence basis | Bespoke candidate measure addressing the missed-meal detection gap in [PS-01](../../operational-demands/problem-scenarios/PS-01.md). No validation evidence is available. |
| Construct measured | Agreement between the system's missed-meal judgement and independently observed meal outcomes. |
| Type | Quantitative. |
| Instrument or procedure | In [EM-05](../evaluation-methods/EM-05.md), compare the system's judgement with an independent observation record for each intended meal at the agreed meal-status decision time. Define the observation window and missed-meal rule before the session. |
| Scoring or coding scheme | Record correctly detected missed meals, missed detections, false alerts and correctly recognised meals. Report the counts and totals for observed missed meals and observed meals separately. Record unknown reference outcomes and unknown system judgements separately. |
| Validity and reliability | Bespoke and unvalidated. Performance depends on the observation record, decision rule and tested situations. Facilitator-selected meal-state events test prototype logic; real detection performance requires the intended sensing setup. |
| Serves | Verification. |
| Burden | An observer, real meals and the intended sensing setup; consent is required for participants and recordings. |

Candidate for a later evaluation; not assessed in the current walkthrough. Used by [EM-05](../evaluation-methods/EM-05.md) to examine the meal-status detection assumed by [F2](../../../2-specification/use-cases/uc01/F2.md).
