# M-02: Reminder success rate

| Field | Description |
| --- | --- |
| ID | M-02 |
| Name | Reminder success rate |
| Status | In Progress |
| Evidence basis | Bespoke behavioural measure derived from failed alarms and notes in [SA-01](../../operational-demands/activities/SA-01.md). |
| Construct measured | Whether a reminder helps Cleber ([ST-01](../../operational-demands/stakeholders/ST-01.md)) initiate the eating activity. |
| Type | Quantitative. |
| Instrument or procedure | Observe whether Cleber begins eating after a reminder and record its outcome. The source proposes camera monitoring; consent and an accurate observation protocol are prerequisites for such use. |
| Scoring or coding scheme | Record success or non-success for each reminder; aggregate as the proportion of observed reminders followed by the defined eating initiation. A response window and handling of refusal/uncertain activity remain to be agreed. |
| Validity and reliability | Bespoke. Response does not establish why a reminder succeeds or fails, and acknowledgment alone is not proof of eating. |
| Serves | Validation. |
| Burden | Low for suitable automated logging; moderate if direct human observation is required. |

Used by [EM-01](../evaluation-methods/EM-01.md) and associated with [HFC-01](../concepts/HFC-01.md). The contextual limitations are
discussed in the [evaluation discussion](../../../3-evaluation/DiscussionAndLimitations.md).
