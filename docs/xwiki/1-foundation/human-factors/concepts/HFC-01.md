# HFC-01: Proper Communication and Interaction

| Field | Description |
| --- | --- |
| ID | HFC-01 |
| Name | Proper Communication and Interaction |
| Status | In Progress |
| Evidence basis | Literature on healthcare communication, human-automation interaction, and robot failure/recovery preferences. Transfer to this meal-support scenario is provisional. |
| Concept statement | Assistive technology should provide understandable information and respond appropriately to the situation rather than give misleading or unnecessarily persistent messages. |
| Human factor addressed | Perceived usefulness, trust and motivation to continue using the tool. |
| Proposed mechanism | Clear communication can support understanding and coordination. False or improper information can undermine trust; excessive persistence may produce annoyance and avoidance. These are design expectations, not established effects of Echo. |
| Source | Leonard, Graham and Bonacum (2004), [The human factor: the critical importance of effective teamwork and communication in providing safe care](https://doi.org/10.1136/qhc.13.suppl_1.i85); Sheridan and Parasuraman (2005), [Human-Automation Interaction](https://doi.org/10.1518/155723405783703082); [RFM-HRI: A Multimodal Dataset of Medical Robot Failure, User Reaction and Recovery Preferences for Item Retrieval Tasks](https://arxiv.org/abs/2603.05641). |
| Conditions and population of validity | The healthcare source concerns communication among clinicians. The automation review and robot-retrieval dataset are not direct evaluations of meal reminders for people with dementia. The project document does not establish transfer to Cleber. |
| Predicted Effect type | Sustained use and reduced avoidance of reminders. |
| Associated Measures | [M-02](../measures/M-02.md) measures response to reminders; [M-03](../measures/M-03.md) can inform the autonomy/acceptance concern, without substituting for a validated trust or annoyance instrument. |

[IDP-01](../../../2-specification/interaction-design-patterns/IDP-01.md) applies the proposed principle through a bounded, calm reminder sequence.
