# ER-01: Formative prototype verification

This is a **planned** Formative verification of the prototype, not a completed report. The prototype is not built yet and no logs or
findings exist.

## Shared fields

| Field | Description |
| --- | --- |
| ID | ER-01 |
| Name | Formative prototype verification |
| Status | Not Started. |
| Mode | Formative: an early, low-cost check whose findings are used to change the prototype before a later validation session. |
| Artifact used | [AT-01](../artifacts/AT-01.md), build [B2](../artifacts/AT-01.md#builds). |
| Evaluation Method(s) applied | [EM-03](../../1-foundation/human-factors/evaluation-methods/EM-03.md), addressing Premises. |
| Ethics | No human participants: the scenarios are scripted and run by an evaluator and a facilitator, so no ethics review or consent is required for this report. |
| Introduction | Probes [UC01-F1-PR1](../../2-specification/use-cases/uc01/UC01-F1-PR1.md), [UC01-F2-PR2](../../2-specification/use-cases/uc01/UC01-F2-PR2.md), [UC01-F3-PR3](../../2-specification/use-cases/uc01/UC01-F3-PR3.md) and [UC01-F4-PR4](../../2-specification/use-cases/uc01/UC01-F4-PR4.md): does the prototype follow the specified reminder, postponement, escalation, logging and summary behaviour? Verification comes before the validation in a later session, so that a failed Claim is not confused with a broken build. |
| Method | Run the nine scenarios of [EM-03](../../1-foundation/human-factors/evaluation-methods/EM-03.md) and compare the event log with the Action Sequence of [UC01](../../2-specification/use-cases/uc01/UC01.md) and each Premise's Verification Criteria, using [M-04](../../1-foundation/human-factors/measures/M-04.md). Use the timing fields of the same log to check whether the reminder intervals and the summary read sensibly. |

## Formative-only fields

| Field | Description |
| --- | --- |
| Finding(s) | To be recorded per Premise after the scenarios are run. None are inferred in advance. |
| Implications | To record what changes in the prototype or the Specification as a result, before any later validation session. |

## Summative-only fields

Not applicable: this is a Formative report with no participants.

## Evidence produced

None yet. After the run, one Evidence entry is created for each of PR1 to PR4. Because [M-04](../../1-foundation/human-factors/measures/M-04.md) is applied against stated criteria, each entry can record whether the criteria were met, partly met or not met. The entries must state that the facilitator supplied the meal-state events, so detection accuracy was not tested.
